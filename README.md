# Birthday Invitation Project 🎂

A simple and elegant birthday invitation web page built with HTML and CSS.

## 🌟 Features
- Responsive card layout with glassmorphic backdrop styling
- Custom background image
- Event details, gift/bring list, and location map link

## 📁 Project Structure
- `index.html` - The main invitation web page
- `background.jpg` - Background image used for the invitation card
- `3.4 Birthday Invite Project/` - Original project source and reference files

## 🚀 How to View
Simply open `index.html` in any modern web browser.
